# APCSP

Working folder for my AP Computer Science Principles project.

## Layout

- `src/` — program code
- `notes/` — planning, research, and write-ups
- `assets/` — images, data files, and other resources

## Getting started

1. Describe the project goals in `notes/plan.md`
2. Add code under `src/`
3. Commit early and often with `git add -A && git commit -m "message"`

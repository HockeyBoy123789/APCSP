# Reference solutions

Working App Lab / JavaScript reference solutions for the coding lessons in Code.org's
csp-2025 AP CSP course, reconstructed from the lesson-by-lesson video guide in
`notes/csp-2025-video-guide.md`.

## What these are

- **Reference implementations**, not official Code.org answer keys.
- Extracted by reading the answer-key / walkthrough videos frame by frame (see
  `scripts/ocr_video.swift`), then cleaned up and commented.
- Each lesson folder has a `README.md` explaining the task, the design elements and
  IDs it expects, and where in the source video the code appears.
- Code is written for **App Lab text mode**. Paste it into the Code tab of a new App
  Lab project and create the design elements with the IDs listed in the README.

## What these are not

- Not a substitute for doing the lesson. The graded "Make" projects and especially the
  **Create Performance Task (Unit 9)** must be your own original work under College
  Board rules. Use these to check your reasoning after you have attempted the task.
- Not guaranteed to match the exact starter code on the level screen. The videos show
  one correct solution; Code.org's levels may use different element IDs or starter
  files.
